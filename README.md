# Nook

Личный менеджер задач для Windows и Android: задачи, привычки, календарь,
блокнот, список фильмов и виджеты. Всё хранится на устройстве, никаких
аккаунтов. По желанию два устройства синхронизируются через твой собственный
приватный репозиторий на GitHub — стороннего сервера нет.

Готовые сборки — в [Releases](https://github.com/volgin07rus-ai/nook/releases).

Раньше приложение называлось Aurora. При первом запуске Nook переносит данные из
старой папки сам, руками ничего делать не нужно.

## Что умеет

### Задачи
- Добавить, отметить выполненной, отредактировать, удалить
- Подзадачи: чек-лист внутри задачи со своим счётчиком
- Заметка, приоритет, дедлайн, категория
- Повторяющиеся задачи: каждый день, неделю или месяц. При выполнении следующая
  создаётся сама, с обнулённым чек-листом и сдвинутым напоминанием
- Напоминания: нативное уведомление Windows в заданное время
- Умная сортировка и группировка по срокам (Просрочено / Сегодня / Завтра / …)
- Над списком — результат дня: сколько из намеченного на сегодня уже сделано,
  серия дней подряд и столбики за неделю

### Привычки
- Отметка кружком на каждый день, серия дней подряд у каждой привычки
- Плитки «сегодня / серия / неделя / месяц» с маленькими графиками
- Столбики за 14 дней и сетка месяца точками; пропущенную отметку можно
  поставить задним числом

### Календарь
- Месяц целиком с цветными точками по категориям в дни, где что-то назначено
- Выбранный день по часам: запись на конкретный час в одно касание

### Фильмы
- Список «хочу посмотреть» с оценкой 0–10 и отметкой «посмотрел»
- Перенос готового списка из записки блокнота

### Категории
- Свой цвет из палитры в 16 оттенков
- Перетаскиваются за ручку слева, порядок сохраняется
- Закрепляются: закреплённая уезжает наверх списка

### Блокнот
- Несколько записок, у каждой своё название или первая строка текста
- Форматирование, списки с галочками, фотографии
- Сохраняется само через 0.4 секунды после того, как перестал печатать

### Синхронизация
- Через приватный репозиторий на GitHub и токен доступа только к нему
- Правка уезжает через несколько секунд, второе устройство подхватывает её в
  пределах минуты
- Сводятся не файлы целиком, а записи по отдельности: правки с обоих устройств
  остаются, удаления не воскресают
- Токен лежит в отдельном файле и в репозиторий не попадает

### Android
- Те же разделы, нижнее меню с шариком, который перелетает к выбранному
  разделу, и полосой, прогибающейся под ним
- Виджеты на главный экран: задачи с цветом категорий, записка, календарь
  месяца. Обновляются сами
- Напоминания уведомлениями, в том числе после перезагрузки телефона

### Отмена
Любое действие откатывается кнопкой во всплывающем сообщении или через Ctrl+Z:
выполнение задачи, удаление, чистка выполненных, восстановление из копии.
История на 40 шагов назад.

### Оформление
- Тёмная и светлая темы, пять акцентов
- Виджет в двух режимах: на рабочем столе (всегда открыт, под окнами) или поверх
  всех окон. Плотность фона настраивается от 10 до 100%
- Значок в трее, автозапуск при входе в Windows
- Экспорт и импорт данных текстом (Настройки → Резервная копия)

## Быстрый ввод

В поле новой задачи можно дописать срок прямо в тексте:

- `Позвонить маме сегодня`
- `Сдать отчёт завтра`
- `Оплатить аренду 12.08`

Слово со сроком уберётся из названия и превратится в дедлайн.

## Виджет на рабочем столе

Панель виджетов Windows 11 (`Win+W`) закрыта для сторонних приложений, поэтому
виджет сделан иначе: окно прижимается к нижнему слою и живёт на рабочем столе.
Другие окна его перекрывают, но свернул их — он на месте, всегда открытый, и в
панели задач не мелькает.

Размытия под виджетом нет намеренно. Windows не даёт стороннему окну удержать
живое размытие: acrylic система гасит у неактивных окон, а legacy blur-behind на
Windows 11 вообще перестал размывать и просто заливает окно плоским серым. В
режиме рабочего стола виджет активен почти никогда, так что любой из эффектов
пропадал бы именно тогда, когда нужен. Обычная прозрачность от фокуса не зависит
и ведёт себя одинаково всегда.

## Напоминания

Очередь напоминаний живёт в Rust и проверяется раз в 20 секунд. Это сделано
намеренно: у скрытых окон Windows душит браузерные таймеры, а напоминание нужно
именно тогда, когда окно свёрнуто. Приложение должно оставаться в трее.

## Запуск

Разработка (горячая перезагрузка):

```bash
npm run app
```

Сборка установщика `.exe`:

```bash
npm run app:build
```

Готовый установщик появится в `src-tauri/target/release/bundle/nsis/`.

Только веб-часть в браузере (без окон и виджета, данные в localStorage):

```bash
npm run dev
```

Проверять типы нужно через `npm run build`, а не `tsc --noEmit`: сборочный
конфиг строже и ловит то, что одиночный прогон пропускает.

## Дизайн-решения

Интерфейс сделан по скиллам из `Память/скиллы/дизайн` (регистр **product**).

- **Цвет в OKLCH.** Все нейтральные поверхности несут след акцентного тона
  (`--hue`), поэтому серый нигде не выглядит мёртвым, но цветность в тёмной теме
  держится на 0.003, чтобы фон читался как почти чёрный, а не коричневый.
- **Акцент выбирается из закрытого набора**, а не пипеткой: произвольный цвет
  разошёлся бы с подкрашенными нейтралями. Графит переворачивается по теме:
  тёмная кнопка на светлом, светлая на тёмном.
- **Базовые стили лежат в `@layer base`.** Неслоёные правила побеждают любые
  слоёные, поэтому неслоёный `button { color: inherit }` однажды молча отменил
  все цветовые утилиты на кнопках и дал тёмный текст на тёмном фоне.
- **Глубина через светлоту и мягкую рассеянную тень**, подкрашенную в тон фона.
- **Пять размеров шрифта** с шагом ~1.2 вместо восьми почти одинаковых.
- **Карточки только как соседи.** Карточка внутри карточки не встречается нигде.
- **Движение только сообщает о состоянии**, 120–220 мс, ease-out, без отскока.
  Единственное исключение — шарик нижнего меню: лёгкий проскок там помогает
  глазу проследить, куда он улетел. Смена вида намеренно **не** обёрнута в
  `AnimatePresence`: переключение состояния не должно ждать завершения
  анимации выхода.
- **Свой выпадающий список** вместо системного, но с полным поведением
  оригинала: стрелки, Enter, Escape, Home/End, роль listbox. Рендерится в
  портале, поэтому не обрезается прокруткой.
- **Контраст проверен в обеих темах** сплошным прогоном по всем текстовым
  элементам. Худшая пара держится выше требования WCAG AA (4.5:1). Отдельная
  ловушка: приглушённый токен подобран под фон канвы, а на подсветке выделения
  фон темнее, поэтому в активных строках текст поднимается на ступень.

## Как устроено

| Путь | Что там |
| --- | --- |
| `src/types.ts` | модель данных, палитры и миграция при загрузке |
| `src/lib/store.ts` | состояние, мутации, история отмены |
| `src/lib/persistence.ts` | запись в JSON-файл (Tauri) или localStorage (браузер) |
| `src/lib/stats.ts` | статистика и сортировки |
| `src/lib/habits.ts`, `src/lib/pulse.ts` | серии, проценты, результат дня |
| `src/lib/sync.ts`, `src/lib/merge.ts` | обмен с GitHub и слияние по записям |
| `src/lib/autosync.ts` | когда обмениваться без кнопки |
| `src/components/Dock.tsx` | нижнее меню с шариком и прогибом |
| `src/components/Select.tsx` | выпадающий список |
| `src/App.tsx` | главное окно |
| `src/components/PhoneApp.tsx` | раскладка для телефона |
| `src/Widget.tsx` | виджет |
| `src-tauri/src/lib.rs` | окна, трей, автозапуск, напоминания, фото, перенос данных |
| `src-tauri/gen/android/app/src/main/java/…` | виджеты и напоминания Android |

Оба окна грузят один и тот же бандл; виджет открывается по адресу
`index.html?view=widget`. Изменения в одном окне рассылаются событием Tauri.

## Где лежат данные

```
%APPDATA%\com.volgin.nook\nook.json
```

Этот файл — и есть вся база. Скопировал его — сделал бэкап. Фотографии из
блокнота лежат рядом, в папке `images`, а настройки синхронизации вместе с
токеном — в отдельном `sync.json`, который никуда не отправляется.

## Закрытие окна

Крестик прячет окно в трей, приложение продолжает работать, чтобы виджет
оставался на экране. Полностью выйти — правый клик по значку в трее → «Выход».
